# 🏆 五大联赛 AI 赛果决策助手

一个基于大语言模型（LLM）与机器学习（Random Forest）的足球数据分析 Agent。

用户只需用自然语言提问，Agent 会自动调用工具查询五大联赛数据、预测比赛概率，并结合 **RAG（检索增强生成）** 检索球队伤停情报，甚至**实时抓取中国竞彩网官方赔率**进行市场去水分析。

**在线试用：** https://你的应用名.streamlit.app *(请替换为你自己的链接)*

## 🌟 核心功能

- **📊 数据洞察**：查询五大联赛的积分榜、近期战绩、历史交锋。
- **🤖 AI 预测**：多联赛随机森林模型（含防数据泄露特征工程），预测胜平负概率。
- **🔮 赛程预测**：自动定位某队“下一场比赛”并给出预测。
- **📰 情报检索 (RAG)**：调用 API-Football 获取该球队最新伤停名单。
- **🎲 盘口价值分析**：实时抓取中国竞彩网官方赔率，计算去水公平概率，进行“模型 vs 市场”的偏差比对。
- **💻 动态 UI**：侧边栏知识库展示，实时的工具调用状态提示。

## 🛠️ 技术栈

- **大模型 Agent**：DeepSeek API (Function Calling)
- **机器学习**：scikit-learn (随机森林 / 逻辑回归自动择优)
- **RAG 技术**：接入外部第三方 API (API-Football) 实现动态检索
- **数据爬虫**：Requests + 竞彩官方接口网关解析
- **前端框架**：Streamlit
- **部署运维**：Streamlit Community Cloud + GitHub CI/CD

## 📁 项目结构

- `streamlit_app.py`：Web 聊天界面 + Agent 主循环 + UI 状态管理
- `tools.py`：核心工具函数（数据查询、模型预测、RAG 检索、竞彩爬虫）及 Schema
- `predict_v2.py`：加载多联赛模型，输出概率
- `train_multi_leagues.py`：多联赛模型训练脚本
- `fetch_multi_leagues.py`：获取五大联赛历史数据与未来赛程
- `models_multi.pkl`：训练好的多联赛模型包
- `matches_*.csv` / `standings_*.csv` / `upcoming_*.csv`：本地数据文件

## 🧠 核心设计说明

1. **防数据泄露特征工程**：训练模型时按日期排序，每场比赛仅使用赛前数据滚动计算特征（场均积分、近5场状态等）。
2. **模型择优机制**：五大联赛分别训练逻辑回归和随机森林，自动对比测试集准确率并择优保存。
3. **RAG 情报增强**：强制大模型在预测比赛前调用伤停查询工具，避免“唯数据论”。
4. **市场定价验证**：接入中国竞彩网真实赔率，通过 Proportional Method 去水，计算市场真实概率。遇到云端 IP 限制时，具备优雅的降级提示逻辑。
